# media-samples/ 演示素材协作指南

本目录继承 [根指南](../AGENTS.md)。先阅读 [素材说明](README.md)，仅维护可进入 Git 的小体积演示内容与来源记录。

## 范围与来源

- 指南建立时仅有目录说明，没有素材或 `MANIFEST.md`。后续按实际需求增加，不为凑目录创建空占位素材。
- 可放自制或获得相应用途授权的图片、音频、绘本示例、图标等；不放真实儿童录音、家庭照片、学习数据、生产数据库或 NAS 运行文件。
- 不从商业 App、绘本、配音或其他仓库批量复制内容。代码许可证不自动授予其中媒体素材的使用权。
- AI 生成素材按实际来源登记；不将生成内容写成原创录音实录、官方图像或已核验授权素材。
- 新增素材时维护 `MANIFEST.md`，记录相对路径、类型、来源、许可证/授权范围、署名要求、凭证位置、版本和用途；无法确认来源时不纳入可发布素材集，并说明缺口。
- 授权凭证仅记录受控存放位置，不把私人购买信息或含敏感内容的原始凭证公开入库。

## 组织与资源清单

- 按需要使用 `image/`、`audio/`、`book/`、`speech/`，主题作为子目录；文件名采用小写英文和连字符，例如 `audio/animals/cat-v1.mp3`。
- 图片优先考虑 WebP，示范音频使用客户端实际支持的 MP3 / M4A 等格式；录音格式样例使用合成或已授权示范，不用真实儿童数据。
- 核验扩展名、真实编码与 MIME 一致。资源清单字段 `path / size / sha256 / mime` 从最终文件计算，不能手填猜测值。
- 内容变更同步更新版本、清单与引用，防止同一缓存路径内容变化而哈希未更新；不在任何下载过程中就地覆盖现有可用资源包。
- 素材原件、压缩后的演示文件与 NAS 部署文件区分，避免覆盖唯一原件。运行时媒体由部署方案管理，本目录不作为用户数据备份目录。
- 当前 README 建议单文件不超过 500 KB、总量超过 20 MB 重新评估存储方式；这些是体积建议，不能为达标牺牲文字可读性或音频清晰度。不擅自引入 Git LFS 或上传外部服务。

## 验证与交付

- 图片实际打开检查尺寸、清晰度和儿童适宜性；音频实际检查格式、时长、音量及截断，不能仅凭文件存在报告可用。
- 核对授权登记、清单哈希、相对路径及示例课程引用；影响离线包时联动客户端缓存与服务端资源清单。
- 报告素材数量、体积、来源、最终路径和实际验证范围。压缩、生成、播放、端侧验证分别说明；默认不提交 Git。
