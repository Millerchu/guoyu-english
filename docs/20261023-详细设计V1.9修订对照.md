## 关键实现契约与限制

### 恢复和重复 ACK

- 恢复控制目录独立于会被还原的数据库，保存撤销、录音墓碑、当前代次、凭证代次及历史签名验证材料，持续复制；普通恢复不能用旧备份覆盖它。
- 旧 ACK 重放必须在原 acceptedAt 后 30 天内，验证原 eventId、原设备身份、hash、儿童和签名接收凭据，再通过新代次重算投影与奖励。已撤销原设备不能借恢复接口重新写入。
- 凭据证明曾在正常窗口被接受的事件，灾难重放时可能已经发生超过 30 天。这是恢复已确认事实的窄例外，不是给真实超窗的新事件补录。
- 无 ACK 的事实仍按当前普通窗口验证。已确认结果和事件去重记录不能跟着旧任务或 90 天增量日志清理。
- 最新控制材料缺失时先保持维护态；本地受损恢复必须作废旧凭证、阻止旧录音回放并禁用不可信重放，明确承认恢复不完整。
- 每天成功备份下目标 RPO ≤24 小时，故障时按最后成功点计算；RTO 暂不承诺。端侧 journal 和原本机录音可能因清理或设备丢失而不可得。

### 固定计划与时区切换

任务在生成时冻结，不等待设备下载 ACK。待生效时区不能因不断领取任务而被无限延后；可提前下载新时区任务，不延长旧时区窗口。

生效点选在旧窗口之后、不与已发行日期重叠的首个新时区午夜。若有切换间隔，只能 FREE 复习，不虚构打卡。该细化属于本稿实现方案：设置 API 先 dryRun 返回生效时间和间隔，家长确认同一 transitionHash 后再修改，避免时区前跳或后退产生重复日期任务。旧事件仍按旧快照和旧时区接收。

1/3/7 天是复习最早到期日；已冻结计划可能使实际复习延后。纠错池进入后续 3 个未冻结任务，不改写已经下载的 7 天。

### 时间与会话

单调时钟锚点绑定 runtimeId。浏览器重开、进程或设备重启默认使旧锚点失效；没有可信时间时先保存未确认归日事实，不确认课程星星。能证明偏差的同运行周期事件可校正，否则由家长审定；不能证明或真实超窗的只导出。

会话跨日必须拆分，累计值从 0 开始。5 秒定期落盘可在异常退出时丢失最后最多 5 秒未保存时长，不将停机时间补入。这不改变已落盘学习动作的可靠保存要求。
