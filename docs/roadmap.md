# 果语开发计划

用途：把《详细设计 V1.9》和已确认的首个学习闭环拆成可以单独开 Pull Request、单独验收的阶段。

- 编写日期：2026-10-29
- 设计依据：[V1.9 详细设计](设计文档/guoyu-english-detailed-design-v1.9.docx)、[V1.9 修订对照](20261023-详细设计V1.9修订对照.md)。第 23 章是唯一持久化模型，第 24 章是唯一接口契约，第 27.3 节是详设里的里程碑。本文件是实施切片，不替代这三处。
- 应用状态：仓库仍没有可运行的服务端、客户端或 Compose。本计划没有执行构建、迁移或部署。
- 使用方式：仓库主人确认本计划后，每次只做一个阶段。一个阶段一个分支、一个 PR，验收通过再开始下一个。不要把后面阶段的表、页面或恢复协议提前塞进当前 PR。

阶段大小按一次实现运行能完成来切，不按日历周数估计。详设里的 M0–M4 周数仍只是未验证的粗估，不作为本计划的工期。

## 已确认的产品要求

这些要求来自后续实现委托，和 V1.9 一起作为阶段范围：

- 服务端：Java 17、Spring Boot 3.x 模块化单体、Maven Wrapper、`groupId` `com.guoyu`、根包 `com.guoyu.english`、PostgreSQL 16+、Flyway。统一响应 `requestId / code / message / data / serverTime`。
- 客户端：uni-app、Vue 3、TypeScript、Pinia，一套代码准备 H5 和 Android。先保证 H5。仓储接口隔离 H5 IndexedDB 与 Android SQLite。
- 部署：最小 `docker-compose.yml`、`.env.example`、Nginx，本地能起数据库、服务和 H5 入口。
- 第一个学习闭环：水果示例课。首页今日课程 → 听一听 → 跟我说（录音和回放）→ 认一认（听音选图）→ 完成。学习动作先落本地状态和 outbox，再经 `/api/v1/sync/push` 上报，`/api/v1/sync/pull` 按游标回传。首页显示进度和星星。
- 跟读音频用可替换的 TTS 生成，语速、音色和停顿可配置，默认为幼儿园大班能跟读的慢速、清晰、亲切语音。

## 慢速跟读的默认参数

S05 把这些值写成提交进仓库的配置（建议 `media-samples/tts/tts.config.yaml`），并在每条音频的元数据里保存实际使用值。没有密钥时也要记下当时的引擎和参数，不能把占位音标成某个云厂商的成品。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `speechRate` | `0.80` | 相对正常语速的倍数。幼儿园大班建议区间 0.75–0.85，配置可改。元数据保存这个倍数；若引擎只用每分钟词数，另外记引擎原始参数 |
| `voice` | 空 | 由当前提供方选择清晰、不尖、不含糊的音色。选定后把提供方的音色标识写入元数据 |
| `style` | `clear-warm` | 发音清楚、语气亲切温和。不使用夸张卡通腔，避免孩子听不清词形 |
| `pauseBetweenWordsMs` | `600` | 单词之间的停顿，方便跟读 |
| `pauseBetweenSentencesMs` | `900` | 句子之间的停顿 |
| `pauseAfterPromptMs` | `400` | 提示音或提示语之后、正式朗读之前的短停顿 |

提供方通过环境变量选择，例如 `TTS_PROVIDER`、`TTS_API_BASE`、`TTS_API_KEY`、`TTS_VOICE`。密钥只存在本地环境，不进 Git、镜像或日志。未选定厂商前保留一个 HTTP 适配骨架，不提交任何一家的 SDK 作为唯一实现。没有密钥时优先调用本机离线 TTS（如 `espeak-ng`），仍套用上表的倍速和停顿；本机也没有时生成明确标记的占位音频，让页面能播放，并在清单里写明它不是正式跟读音。

`media_asset` 至少区分这些来源：`HOMEMADE`（自制图或人声）、`LICENSED_THIRD_PARTY`（已授权第三方）、`AI_GENERATED`（云端或模型 TTS）、`OFFLINE_TTS`（本机离线引擎）、`PLACEHOLDER`（占位音）。同时保存生成工具、音色、语速、停顿、原文本和生成时间。路径只存相对 `storage_key`。

## S01 后端脚手架与健康检查

- 目标：有一个能编译、能对 PostgreSQL 跑迁移、能回答健康检查的 Spring Boot 进程。
- 依赖：无。
- 目录：`server/`、`server/README.md`、`server/AGENTS.md`、根 `AGENTS.md` 里已经过时的「没有 pom、设计仍停在 V1.7」描述。
- 做什么：Maven Wrapper；Java 17；Spring Boot 3 的当时最新 3.x 补丁，版本写进 POM。根包 `com.guoyu.english`。只建 `common` 里的统一响应、请求号、错误码骨架和健康检查 `GET /api/v1/system/health`。Flyway 脚本 `V1__baseline.sql` 不建业务表，只证明迁移能执行。`local` 配置从环境变量读数据库，不写真实口令。测试使用 Testcontainers 的 `postgres:16`。集成 MyBatis-Plus 的依赖可以先引入并在测试里跑一条最简单的查询，确认 ORM 选择已经落地。
- 不做什么：课程、儿童、同步、认证、媒体接口，以及第 24 章其余端点。
- 验收：在 `server/` 执行 `./mvnw test`。健康检查返回 HTTP 200，JSON 含 `requestId`、`code=OK`、`message`、`data`、`serverTime`（UTC ISO-8601）。`data` 只有版本和就绪状态，没有口令、地址和令牌。测试断言 Flyway 已应用到 V1。
- 风险：环境没有 Docker 时 Testcontainers 起不来。失败就如实记，不用 H2 蒙过。Java 17 不在机器上时先安装再测，不改成别的语言级别。

## S02 客户端脚手架

- 目标：uni-app 工程能安装依赖并构建 H5，页面结构符合儿童端的空壳约束。
- 依赖：无。与 S01 并行。
- 目录：`client/`、`client/README.md`、`client/AGENTS.md`。
- 做什么：按官方脚手架锁定 uni-app、Vue 3、TypeScript、Pinia 和包管理器版本，提交锁文件。`engines` 写成该脚手架实际要求的 Node 版本。应用 ID 预留 `com.guoyu.english`。只有首页壳：一屏一件事、主按钮高度按 56–64dp 的目标来做、进入页面不放音频。建立 `repositories` 接口以及 `h5/`、`android/` 两个空实现，页面不直接碰存储。Pinia 只放显示状态。
- 不做什么：课程数据、录音、同步、IndexedDB 表结构、Android 工程的真机打包。
- 验收：按落地后的 `package.json` 执行安装、类型检查和 `build:h5`。构建产物里能看到首页壳。Android 目录存在但本阶段不声称 APK 可用。
- 风险：uni-app CLI 与 Node 版本不匹配。以脚手架生成结果为准改脚本，不从别的 Vite 项目抄版本。

## S03 本地 Compose

- 目标：一条命令在本机拉起数据库、后端和 Nginx，并从网页入口看到健康检查。
- 依赖：S01、S02。
- 目录：`deploy/`、`server` 的容器构建文件、H5 构建产物如何进入 web 镜像的说明、`docs/development.md`（到这一步才写，因为命令这时才真实）。
- 做什么：`docker-compose.yml` 包含 `guoyu-english-db`（`postgres:16-alpine`，不把 5432 映射到宿主机）、`guoyu-english-server`、`guoyu-english-web`。数据库健康检查用 `pg_isready`，服务依赖健康的数据库。Nginx 把 `/api/` 转到后端的 `/api/`，不重复或截掉 `v1`；H5 走前端路由回退；`/media/` 指向只读空目录。`.env.example` 只用占位符，例如 `DB_PASSWORD=CHANGE_ME`。端口 8080 只作为本机 HTTP 联调，文档写明录音仍需要可信 HTTPS。
- 不做什么：备份容器、TLS 证书、真实 NAS 路径、录音可写目录。
- 验收：用示例环境文件检查 Compose 配置时不打印真实密钥。`docker compose up` 之后，`GET http://127.0.0.1:8080/api/v1/system/health` 返回与 S01 相同的成功结构。确认宿主机没有发布 5432。把真实命令写进 `docs/development.md` 和 `deploy/README.md`，删掉「文件不存在」的说法。
- 风险：镜像构建慢或当前 CPU 架构拉不到镜像。web 镜像若没拷进 S02 的构建产物，验收会只看到默认页，这不算通过。

## S04 水果课数据

- 目标：数据库里有一节可查询的水果课，媒体字段能区分自制、授权和 AI 来源。
- 依赖：S01。
- 目录：`server/` 的 course、media 包，Flyway 新版本，`media-samples/image/food/`，`media-samples/MANIFEST.md`。
- 做什么：新增迁移，只建闭环需要的内容表：`course_theme`、`lesson`、`lesson_step`、`lexeme`、`media_asset`。主键 BIGINT Identity。`media_asset` 含相对路径、MIME、大小、SHA-256，以及来源种类、生成工具、音色、语速、各项停顿、原文本、生成时间、许可证。枚举做成独立 Java 枚举。种子数据：主题 Food，课 `fruit-001`，三步 `LISTEN`、`SPEAK`、`RECOGNIZE`，词 apple / banana / orange，句 “I like apples.”。图片用本仓库自制的简单 SVG，登记为 `HOMEMADE`。提供 `GET /api/v1/lessons/fruit-001?version=1`。课程版本不可变，修正内容用新版本迁移，不改已执行脚本。
- 不做什么：音频文件、儿童、任务发行、同步。不下载来源不明的水果图片。
- 验收：`./mvnw test` 覆盖迁移和课程查询。测试计算 SVG 的大小与 SHA-256，与种子一致。响应仍是统一外壳。`MANIFEST.md` 每张图一行来源。
- 风险：SVG 被客户端当图片用时兼容性不足。本阶段只要求文件和接口正确，播放放到 S10；若 H5 不能画 SVG，再在 S10 转成同等自制栅格图并改哈希。

## S05 慢速跟读音频

- 目标：用一份可替换的生成工具，为水果课的词和句子产出慢速音频和来源记录。
- 依赖：S04 的字段约定。脚本可以按本文件的字段先写，入库脚本跟随 S04 的真实列名。
- 目录：`media-samples/tools/`、`media-samples/tts/tts.config.yaml`、`media-samples/audio/food/`、`media-samples/MANIFEST.md`、`media-samples/README.md`。
- 做什么：Python 3 命令行工具，按词条和句子批量生成。提供方是接口，至少包括离线引擎、占位音频，以及一个只读环境变量的 HTTP 适配骨架。默认参数用上一节的表。输出音频到媒体目录，并写出元数据（来源、工具、音色、`speechRate`、停顿、原文本、生成时间、大小、SHA-256）。无密钥时走离线 TTS 或占位音。生成结果若体积适合 Git，就提交示例音频；正式听审前，清单写明是否已经人工听过。
- 不做什么：不接入某一家商业 SDK 作为唯一实现，不把密钥写入脚本默认值，不在 Spring Boot 或儿童页面里直接调用云端 TTS，不生成儿童姓名相关语音。
- 验收：不设置密钥运行工具，得到三个词和一句的音频。用文件头或 `ffprobe` 一类工具确认是真实音频而不是空文件。元数据中的语速为 0.80，单词停顿 600 毫秒、句子停顿 900 毫秒，除非命令行显式改过。改一个环境变量指向另一套参数时，输出元数据跟着变。README 说明提供方怎么换、默认值为什么适合 5–6 岁跟读。
- 风险：离线引擎音质不像亲切人声。占位音只能用来打通播放，不能在清单里写成正式教材音。云端试听要等主人选定厂商并在本地配置密钥之后另做，不阻塞闭环。

## S06 引导、建档与配对

- 目标：从空库创建家庭和儿童，并用一次性配对码发放可撤销的设备令牌。
- 依赖：S01。
- 目录：`server/` 的 auth、child 包，新的 Flyway 版本，`.env.example` 里的引导码变量名。
- 做什么：表 `family`、`child_profile`、`client_device`、`device_child_binding`，以及家长 PIN 的盐和 Argon2id 哈希、失败次数。PIN 为 4–6 位。默认时区 `Asia/Shanghai`。接口按第 24.7 节的最小子集：用环境变量中的一次性引导码调用 `POST /api/v1/parent/bootstrap`，`POST /api/v1/parent/children` 建档，`POST /api/v1/parent/pair-codes` 发 5 分钟配对码，`POST /api/v1/devices/pair` 换设备令牌。建档请求带 `Idempotency-Key`，相同键和相同内容不重复建儿童。连续失败 5 次后延迟增加，计数存在数据库里。撤销设备后旧令牌不能再访问受保护接口。日志不打印 PIN、引导码和令牌。
- 不做什么：不实现恢复码、时区预览、七天任务。种子 SQL 不写儿童。不提供「PIN 直接换设备令牌」的第二入口。
- 验收：`./mvnw test` 从空库走完引导、建档、配对。重复建档返回原来的儿童。错误 PIN 达到阈值后出现延迟。撤销后的令牌被拒绝。仓库和测试输出里没有可用的真实 PIN。
- 风险：Argon2 参数对低内存环境偏重。先按详设的 64 MiB、3 次迭代、并行度 1 做；若测试容器稳定失败，在 PR 里记录实测值，不悄悄改成可离线破解的弱哈希。

## S07 同步与幂等账本

- 目标：同一事件重复上报不会重复记账，同一天重复完成不会重复发跟读星或贴纸。
- 依赖：S04、S06。
- 目录：`server/` 的 sync、learning、reward 包，新的 Flyway 版本。
- 做什么：表 `learning_event`（`event_id` UUID 主键，含请求哈希和当时的处理结果）、`star_ledger`（`child_id + grant_key` 唯一）、`badge_award`、`daily_checkin`、`sync_stream`、`sync_change_log`、`device_sync_cursor`。家庭创建时生成一个 `streamEpoch`。`POST /api/v1/sync/push` 在一个事务里：校验设备和儿童、锁家庭流、按 `eventId` 查重、新事件才插入并更新进度、星星、贴纸和变更日志。重复且哈希相同返回 `DUPLICATE` 和原来的结果。同一 `eventId` 换内容返回 `EVENT_ID_REUSED`，不加星。跟读星的键为 `{childId}:{learningDay}:SPEAK_STAR:{lexemeId}`，增量固定 1。当天课程完成发 `CHECKIN_STICKER`，不另发签到星。`GET /api/v1/sync/pull` 按游标返回已提交变更和 `nextCursor`。批次上限 100 条、256 KiB。学习日按儿童档案时区计算。
- 不做什么：不签 receipt，不切换 epoch，不处理 30 天窗口之外的补录，不做录音上传，不把客户端传来的星星数写进账本。
- 验收：对 PostgreSQL 的测试至少包括：同一 `eventId` 推两次，第二次为 `DUPLICATE`，`star_ledger` 行数不变；同一词用新的 `eventId` 再完成一次，仍然只有一颗星；同一天用另一批事件再次完成课程，贴纸仍是一张，且没有签到星行；哈希冲突不加星；事务中途失败时事件、星星和变更日志一起回滚。
- 风险：先查后插在并发下不够。测试要包含两次并发插入同一 `eventId`，以唯一约束兜底。Pull 游标只前进到已提交行，不用普通序列号代替家庭流锁。

## S08 今日任务

- 目标：首页接口返回这名儿童今天的水果课，而不是由客户端自己挑一节课。
- 依赖：S04、S06。可与 S07 并行，联调前两者都要完成。
- 目录：`server/` 的 learning 包，`daily_assignment` 迁移。
- 做什么：建档或首次领取时，为今天发行一条任务，唯一键是儿童加学习日。快照冻结课版本、三步、词条、时区和完成规则，并保存哈希。`GET /api/v1/home/today?childId=` 返回任务、三步进度和奖励概览。没有任务时明确返回空状态，不临时编一节课。设备时区不改变学习日。
- 不做什么：不预生成未来六天，不根据昨天有没有完成而改写今天。那是 S14。
- 验收：同一天重复领取得到同一 `taskId` 和哈希。把数据库时区或请求里的设备时区改掉，学习日仍按 `Asia/Shanghai`。未授权的儿童 ID 读不到任务。
- 风险：S07 的进度字段和 S08 的快照若分两次设计，联调时对不上。两边都只认快照里的 `stepId` 和 `lexemeId`。

## S09 本地仓储与 outbox

- 目标：浏览器里一次写入学习状态和待同步事件，失败时界面不能显示已保存。
- 依赖：S02。事件字段以 S07 的契约为准；若 S07 尚未合并，先按本计划 P04、P05、P08 写类型，合并时对准真实 JSON。
- 目录：`client/src/repositories/`、`client/src/sync/`、`client/src/api/`。
- 做什么：H5 用 IndexedDB。一次学习动作在同一事务里写进度、outbox 和预估星星。`eventId` 创建时生成并持久化，重试不换新 ID。Pull 的变更全部写成功之后才保存 `nextCursor`。Android 实现同一个接口，可以用最小的内存或未接真机的 SQLite 占位，但必须能在工程里编译，并在说明里标明没有真机验证。API 类型手写明确字段，不用 `any`。
- 不做什么：不在这个阶段做三个学习页面，不实现资源包下载。
- 验收：用自动化测试覆盖事务失败不留半条 outbox、重复入队不换 `eventId`、Pull 写到一半不推进游标。H5 构建仍然通过。
- 风险：IndexedDB 没有 SQLite 那样的跨表事务语义。测试要绑在真实浏览器存储或项目选定的 IndexedDB 假实现上，不把 Pinia 内存当持久化。

## S10 听一听、跟我说、认一认

- 目标：儿童可以在 H5 里不连服务器，把一节已缓存的水果课学完。
- 依赖：S05、S09。页面用 S04 的课结构。
- 目录：`client/src/pages/learn/`、`client/src/components/`、`client/src/media/`、`client/src/styles/`。
- 做什么：首页进入今日三步。听一听：点按后播放慢速词音频，三个词都听过才算完成，进入页面不自动大声播放。跟我说：显式开始录音，显示正在录音和剩余时间，单次最长 30 秒，可停止和回放，离开页面释放麦克风和播放器。认一认：听音选图，答错只显示「再听一次」或「再试试」，不出现红色失败文案。完成后保留进度，返回不重头清空。全部动作用 S09 的仓储写入。非安全上下文打开录音时，明确提示需要可信 HTTPS，不静默失败。主按钮保持唯一，高度达到儿童端目标。
- 不做什么：不上传录音，不调用云端打分，不实现读一句和小游戏。
- 验收：构建 H5。在浏览器里从首页走完听、说、认、完成，刷新后进度还在。答错路径和录音状态各走一次。能播放 S05 的音频。保存截图到 PR 说明所能引用的位置。Android 仍写明未做真机。
- 风险：自动化浏览器没有麦克风权限。录音步骤至少验证权限被拒绝时的提示；若环境允许，再验证一段真实回放。不能把只看到页面截图写成录音已通过。

## S11 第一个闭环联调

- 目标：本地学完后上报，首页显示服务端的进度和星星，重复上报不增加星星。
- 依赖：S03、S06、S07、S08、S10。
- 目录：`client/src/sync/`、首页、`docs/api/api-v1.md`（只记录已经实现的接口）。
- 做什么：启动、回到前台和手动操作触发同步，避免两套同步同时跑。顺序是 Push 再 Pull。逐条处理 `ACCEPTED`、`DUPLICATE`、`REJECTED`，不能因为 HTTP 200 就清空整批。首页星星按 P14 合并。配对使用 S06 的配对码。儿童页面不显示服务器 IP 和管理按钮。
- 不做什么：不实现七天计划、日历、家长报表和录音上传。
- 验收：Compose 或本地后端加 H5。走一遍配对、学习和同步。数据库里该词只有一颗跟读星、当天只有一张贴纸。把同一 outbox 再推一次，星星数量不变。首页能看到进度和星星。PR 里写实际命令、浏览器结果和截图。`./mvnw test` 与 H5 构建都要在这个阶段的说明里引用最近一次真实结果。
- 风险：示例环境是 HTTP，桌面浏览器可能拒绝录音。联调可以先用已允许的本地安全上下文，或把录音限制如实写进结果；不能把 HTTP IP 上的失败说成功能缺陷已修复。

## S12 读一句与课程小游戏

- 目标：新发行的课包含详设五步里剩下的两步，并按句和课发星。
- 依赖：S11。
- 目录：课程种子、学习页、奖励规则。
- 做什么：句子 “I like apples.” 走播放示范、录音和回放。课程内小游戏使用 `context=COURSE`，完成一局。新的任务快照把必做步骤改为五步。读一句的键是 `{childId}:{learningDay}:READ_STAR:{sentenceId}`，小游戏的键是 `{childId}:{learningDay}:COURSE_GAME_STAR:{lessonId}`，各固定 1。已经发出的三步水果任务保持原哈希，不补步骤。
- 不做什么：不改自由游戏，不把小游戏做成独立大厅。
- 验收：新任务必须五步才发贴纸。同一句、同一课重复完成不加星。旧三步任务的完成条件不变。
- 风险：新旧快照若共用一个完成判断，会把已经学完的三步课重新变成未完成。测试要同时覆盖两个版本。

## S13 麦克风跳过

- 目标：不能录音时，孩子仍可听完示范并跳过，课程能完成，但该词或该句没有星。
- 依赖：S10；若 S12 已合并，读一句使用同一规则。
- 目录：跟我说、读一句、同步事件 `STEP_SKIPPED`。
- 做什么：权限被拒绝或没有麦克风时，提供明确的跳过。跳过计入该快照的完成，家长侧以后能看到原因。之后补录，只按原来的 `grantKey` 发一次星。
- 不做什么：不把跳过伪装成录音成功，不上传空文件。
- 验收：跳过事件重复推送不加星。补做成功后该词只有一颗星。完成状态仍然成立。
- 风险：跳过按钮若和主按钮并列，会破坏一屏一件事。只在录音不可用时显示跳过。

## S14 七天任务

- 目标：服务端一次发行今天起最多七天的固定计划，之后不再改这些行。
- 依赖：S08。
- 目录：learning 任务发行。
- 做什么：`child_id + learning_day` 唯一。发行时写入 `issuedThrough`。重复领取不改哈希。昨天没完成，也不能替换已经发出的明天。时区字段先保存，真正的生效预览可以留在本阶段的接口里：`dryRun` 只返回生效时间，确认后才写入；若这样做大过一个 PR，就只冻结七天并把时区切换明确列为未做。
- 不做什么：不实现纠错池和 1/3/7 天复习调度的全部规则，那部分在 S18 之后只影响未发行任务。
- 验收：连续请求七天，行数不增加、哈希不变。尝试更新已发行快照被拒绝。
- 风险：时区切换只做一半会让两端算出不同的生效日。没做完就不要暴露修改时区的按钮。

## S15 资源包

- 目标：水果课的图和音频可以按清单校验后切换，失败时旧内容还在。
- 依赖：S05、S11。
- 目录：`content` 包、`client/src/sync/` 的资源部分、Nginx 媒体目录。
- 做什么：`content_pack` 与文件清单，字段含相对路径、大小、SHA-256、MIME。客户端下到临时区，全部校验通过才切换。一个文件失败保留旧包。H5 用 Cache Storage 和 IndexedDB 索引；Android 接口先定义私有目录行为。
- 不做什么：不把容量做到 300 MiB 的完整策略，不自动下载绘本。家长可见的占用显示可以只做这一小包。
- 验收：改坏一个字节后不切换。断在中途，原包仍能播放。清单哈希由工具计算，不手填。
- 风险：浏览器配额很小。验收记录实际占用，不宣称已经满足详设的七天预下载。

## S16 家长今日概览

- 目标：家长用 PIN 看到今天有没有完成、星星是否已确认、有没有跳过录音，并可以撤销设备。
- 依赖：S06、S11、S13。
- 目录：`client/src/pages/parent/`、`GET /api/v1/parent/dashboard`。
- 做什么：长按只是发现入口，进入前仍要 PIN。NAS 不可达时不新建家长会话。概览含今日状态、待同步数和跳过原因。撤销走 S06 已有能力。儿童页仍然没有这些控件。
- 不做什么：不做作业时长图表，不做周月报。
- 验收：错误 PIN 进不去。正确 PIN 能看到与服务端一致的今日结果。撤销后该设备 Push 被拒绝。离线时不能打开新的管理会话。
- 风险：H5 把 PIN 放进日志或查询字符串。审查网络封装和测试输出。

## S17 最小学习日历

- 目标：按儿童时区显示一个月里哪些天完成了，同一天只显示一次。
- 依赖：S07。
- 目录：`GET /api/v1/learning/calendar`、日历页。
- 做什么：完成来自 `daily_checkin`，不是单独的签到按钮。月接口一次返回整月。未完成的日期不用负面文案。
- 不做什么：不计算跨月连续徽章的展示，那是 S25。不把两台设备的时长相加。
- 验收：同一天两批完成事件只出现一个完成日。时区边界附近的事件落在档案时区的那一天。
- 风险：用服务器本地日期会在 UTC 午夜划错。测试固定一个上海时区的 23:30 和 00:30。

## S18 服务端判题

- 目标：认一认的对错由服务端按题目版本计算，熟悉度只看首次独立作答。
- 依赖：S07、S10、S14。
- 目录：`QUESTION_ANSWERED` 的处理、题目快照。
- 做什么：事件带稳定的题目、选项、尝试组和从 1 开始的尝试序号。最终答对可以完成认一认，但不把重试算成一次新的熟悉样本。同一序号换答案返回冲突。熟悉度变化只影响尚未发行的任务。
- 不做什么：不在这个阶段做完整的三天纠错调度 UI。
- 验收：首次答错再答对，完成但熟悉度不加。重复同一首次答案不增加样本。客户端声称答对而选项错误时，服务端记为错。
- 风险：选项顺序打乱后如果上传的是屏幕位置，换设备就会判错。契约只收选项 ID。

## S19 自由复习

- 目标：已缓存的水果课可以再玩一次，不发星、不打卡。
- 依赖：S12、S15。
- 目录：一个最小复习入口，不要完整游戏大厅。
- 做什么：`context=FREE` 的事件单独投影。没有当日任务时也能进入已缓存内容。
- 不做什么：不新增题型，不发贴纸。
- 验收：自由复习前后，星星和 `daily_checkin` 不变。课程模式的完成规则不变。
- 风险：复用课程页时把 FREE 写成 COURSE。测试检查事件上下文。

## S20 录音上传

- 目标：家长打开同步后，录音可以按标识幂等保存；关掉或删除后，同一标识不能重新变成可播放。
- 依赖：S06、S11。
- 目录：`speech` 包、独立的 recordings 卷。Nginx 不公开这个目录。
- 做什么：默认 `recordingSyncEnabled=false`。打开后才接受上传。同一标识、同一哈希重试不存两份。删除写墓碑，之后的上传得到已删除。学习完成不依赖文件是否上传。单文件不超过 5 MiB、30 秒。
- 不做什么：不接第三方发音评分，不把录音放进 Git。
- 验收：默认配置下上传被拒绝，本地完成仍然有效。重复上传只有一份。删除后再次上传失败，学习事件还在。
- 风险：墓碑和文件删除的顺序做错会复活录音。本阶段按「先墓碑、后文件」实现最小版本；跨进程锁如果做不完，要在 PR 里写明还差什么，不能宣称 T31 已通过。

## S21 每日备份

- 目标：有一份可审查的备份命令，把数据库和媒体清单放到数据目录以外的位置。
- 依赖：S03。
- 目录：`deploy/backup/`、`deploy/README.md`。
- 做什么：脚本调用数据库自带的转储工具，并记录媒体文件的相对路径、大小和 SHA-256。`.env.example` 增加备份目录占位。文档写明默认保留设想是 30 天，以及 Flyway 不能自动退回旧结构。
- 不做什么：不在本阶段对真实 NAS 演练恢复，不备份尚未存在的私有录音，除非 S20 已合并。
- 验收：对本地 Compose 跑一次备份，检查转储文件和清单存在，且清单哈希与当时文件一致。PR 写明「恢复未验证」。
- 风险：脚本把 `.env` 打进备份包的公开说明。输出要脱敏。

## S22 恢复代次

- 目标：从一份旧备份恢复后，旧游标不能把新变更漏掉，旧设备令牌也不能继续使用。
- 依赖：S07、S21。若 S20 已存在，恢复步骤包含录音墓碑。
- 目录：sync 恢复流程、部署文档。
- 做什么：恢复后生成新的 `streamEpoch`，提升凭证代次，旧令牌、会话和配对码失效。客户端发现代次变化后停止普通 Push，先取完整快照。家长确认后，才重放仍在保留期内、哈希相符的已确认事件。重放使用原来的 `eventId` 和 `grantKey`，不第二次发星。
- 不做什么：不承诺零丢失，不把真实超过 30 天且从未确认的事件补进账本。
- 验收：在一份拷贝出的测试库上，把游标置于备份之后，恢复后仍能收到备份点之后的新变更。同一奖励键只有一行。旧令牌被拒绝。没有第二份隔离环境时，不把文档演练写成 NAS 已通过。
- 风险：这是本计划里最大的一段。若一次做不完，只拆成「代次和令牌失效」与「重放」两个 PR，不要顺便重写同步主路径。

## S23 短绘本

- 目标：有一本 6 到 8 页的自制绘本，点读和完成次数符合「整本读完才算一本」。
- 依赖：S15、S07。
- 目录：book 包、绘本页、自制图文。
- 做什么：冻结必读句。自然播放结束才记已读。同一本书首次读完计 1，重读另计。最大页码只用于翻页。
- 不做什么：不导入任何现成绘本扫描件，不一次做附录 B 的 3 到 5 本。
- 验收：跳到最后一页不算读完。补齐每一句后计 1 本。同一天再读一遍，总本数仍是 1。
- 风险：音频和句子版本不一致。沿用 S05 的元数据，句子文本改了就必须新版本。

## S24 自然拼读

- 目标：提供一组字母音练习，结果仍走同一条同步链路。
- 依赖：S15。
- 目录：phonics 包、一个练习页。
- 做什么：先做 6 个与已有词有关的字母音，例如水果课能用到的短元音，避免另起一套生词。音频仍用 S05 的工具生成并登记。
- 不做什么：不把自然拼读算进水果课的每日必做，除非另发一版任务快照。
- 验收：练习可播放、可作答，并形成现有类型的学习事件。没有事件就没有星星。
- 风险：字母音对离线 TTS 特别不友好。听审前标成未审音频。

## S25 奖励页与徽章

- 目标：儿童能看到已确认星星和尚未覆盖的预估，连续 3、7、14、30 天的徽章各得一次。
- 依赖：S07、S17。
- 目录：reward 页、`badge_award` 的连续学习规则。
- 做什么：贴纸图案可以变化，但是否获得不随机。断学习只清当前连续天数，不收回已发徽章。儿童端不播放扣星动画。
- 不做什么：不实现商店或消耗星星。
- 验收：同一里程碑重复同步只有一枚徽章。预估星星在 Pull 覆盖后不翻倍。
- 风险：连续天数用设备本地日历。必须复用 S17 的学习日。

## S26 周报与月报

- 目标：家长按自然周和自然月看到完成、时长、跳过和已确认星星。
- 依赖：S16、S17。
- 目录：report 包、家长报告页。
- 做什么：周从周一开始，月按儿童时区的自然月。数字能从事件和投影重新算出。
- 不做什么：不加入绘本本数，直到 S23 完成；未完成时报告里该项显示为还没有绘本数据。
- 验收：同一天两台设备不把时长相加。跳过次数与 S13 的事件一致。
- 风险：报告若另写一套统计，会和日历不一致。查询只读已有投影。

## S27 扩充主题

- 目标：在机制不再改动的前提下，按附录 B 增加 Animals 和 Colors。
- 依赖：S12、S15、S05。
- 目录：`media-samples/`、课程迁移。
- 做什么：每个主题一个 PR。沿用同一课结构、同一 TTS 配置和同一清单格式。Animals 使用详设里的 cat、dog、bird、fish、rabbit 时，只使用自制或已登记来源的图和音频。
- 不做什么：不在内容 PR 里改奖励公式或同步协议。不一次提交 12 个主题。
- 验收：新课版本可查询、音频哈希与清单一致、旧水果课仍能学完。
- 风险：顺手改共用组件导致水果课回退。每个主题 PR 都要再走一遍水果课的最短路径。

## S28 Android 本地实现

- 目标：SQLite 仓储和录音接口达到可以打包安装的程度，并单独记录真机结果。
- 依赖：S10、S11。
- 目录：`client/` 的 android 适配、`manifest` 中的应用 ID 和最低 Android 8.0 / API 26。
- 做什么：用与 H5 相同的仓储接口保存状态和 outbox。录音走原生权限。没有真机时，PR 只声称工程配置和单元测试，不声称 APK 已验收。
- 不做什么：不改 H5 已经通过的交互，不把 Android 的明文 HTTP 当作正式录音环境。
- 验收：打包命令按实际脚本执行。若拿到设备，再走一遍水果课和同步；没拿到就在 PR 里写未验证。
- 风险：条件编译把 H5 构建弄坏。本阶段的验收必须包含一次 H5 构建。

## S29 家庭环境验收

- 目标：在局域网和可信 HTTPS 上核对录音、离线再同步，以及备份恢复的真实边界。
- 依赖：S11、S15、S21；恢复结论还依赖 S22，录音上传结论还依赖 S20。
- 目录：`deploy/README.md`、一份日期开头的验收记录。
- 做什么：记录健康检查、数据库端口未暴露、媒体只读、HTTPS 下录音可用、NAS 不可达时能学完、恢复连接后星星不增加。只断公网不算离线通过。未做的项目保持「未验证」。
- 不做什么：不开放公网端口，不改路由器，不在生产库上做恢复实验。
- 验收：记录是真实操作的结果，包含环境和失败项。没有家庭 NAS 时，本阶段不开始，也不用本机 Compose 代替 NAS 结论。
- 风险：把 S11 的本机结果抄进家庭验收。两类环境分开写。

## 整个计划都不做的事

- 不拆微服务，不引入 Nacos、Seata、Redis、消息队列。
- 不做开放式 AI 对话、发音评分和儿童录音出站。TTS 只在维护者生成教材音频时使用。
- 不做商城、支付、排行榜和公开账号。
- 不把商业 App、教材页或其他仓库的图、音频、课文复制进 `media-samples/`。
- 不把 H5 桌面浏览器的结果写成平板、APK 或 NAS 已验收。

## 建议的确认顺序

先确认 P01–P14，尤其是这三件会影响第一步怎么写：

1. 第一个闭环是否接受「三步水果课 + 贴纸而不是签到星」。
2. 恢复是否可以放在 S21、S22，而不是放在写任何学习数据之前。
3. 无密钥时是否接受离线 TTS 或占位音，正式音色等选定厂商后再换。

确认后从 S01 开始。S01 与 S02 可以并行。
