# client/ 客户端协作指南

本目录继承 [根指南](../AGENTS.md)。工作前阅读 [客户端说明](README.md) 及当前任务对应设计；本文件只补充客户端规则。

## 现状与目标结构

- 工程按官方 `dcloudio/uni-preset-vue#vite-ts` 初始化。`pages.json`、`manifest.json` 和页面都在 `src/`，这是该 CLI 的实际位置。
- 包管理器是 npm，锁文件是 `package-lock.json`。`engines.node` 写成脚手架锁定的 Vite 5.2.8 所要求的 `^18.0.0 || >=20.0.0`。
- Pinia 按 [uni-app Vue3 Pinia 说明](https://uniapp.dcloud.net.cn/tutorial/vue3-pinia.html) 接入，版本固定为文档中的内置版本 `2.1.7`，并在 `createApp` 里返回 `Pinia`。npm 上更新的 Pinia 要求 Vue 3.5，和本脚手架的 Vue 3.4 不一致。
- 已有首页壳 `src/pages/index/index` 和 `src/styles/tokens.css`。`src/pages.json` 只注册这一页，没有 tabBar。
- `src/repositories/` 只有共享契约里的方法签名。调用会拒绝，失败反馈的 `saved` 固定为 `false`。S09 再实现持久化。不要用空列表或空课程表示已经保存。
- Android 应用 ID 已写为 `com.guoyu.english`，`minSdkVersion` 为 26。本阶段没有 APK，也没有真机结果。
- 下面表格里还没出现的目录，使用前先确认是否已经创建。学习页、组件、存储实现、同步和 HTTP 都不在本阶段。

| 目标路径 | 职责 |
| --- | --- |
| `src/pages/` | 儿童学习、绘本、奖励、家长页面与路由 |
| `src/components/`、`src/styles/` | 复用组件与设计 token |
| `src/stores/` | 档案、学习、奖励、同步界面状态 |
| `src/repositories/` | 持久化接口、Android / H5 存储实现 |
| `src/sync/` | outbox、Push/Pull、重试、资源包管理 |
| `src/api/` | HTTP、统一响应、错误码与契约类型 |
| `src/media/` | 音频播放、录音与权限适配 |

## 实现规则

- 页面通过仓储接口访问数据，不在页面直接操作 SQLite、IndexedDB 或散落 HTTP 请求；Pinia 中的显示状态不能替代持久化队列。
- Android 使用 SQLite 和 App 私有文件；H5 使用 IndexedDB、Cache Storage，并按浏览器能力处理缓存与存储配额。不要假设二者拥有相同事务或文件语义。
- 平台专属存储与媒体能力放在适配层，通过接口和必要的条件编译接入；避免在每个页面重复判断平台。
- 接口、事件、资源清单和页面状态使用明确 TypeScript 类型；边界数据先校验，避免用 `any` 或大范围类型断言绕过契约。
- 修改布局先确认实际命中的组件、样式选择器、端侧尺寸和状态，再做最小修复；不要凭截图推测就改全局样式。
- 新功能前搜索现有选择器、详情页、表单及提交入口，复用原业务链路；同步更新路由、入口、字段、默认值、校验、加载/空态和家长权限。
- tabBar、游戏入口、跳过录音后的完成判定等存在评审分歧，涉及实现时统一方案并更新设计，不能把 README 的建议路由直接当成已确认契约。

## 离线与同步

- 学习动作先以同一持久化事务保存本地状态和 outbox，再更新成功界面；失败不能显示已可靠保存。
- `eventId` 在事件创建时产生并持久化，重试复用原值。逐条处理 ACK，不能因 HTTP 200 就清空整批事件；拒绝事件保留原因并按契约处理。
- 当前设计的 Push 上限为 100 条 / 256 KB，退避为 5s、15s、45s、最长 5min 并带抖动；接入时与服务端统一字节口径、ACK 和重试规则。`429` 遵守 `Retry-After`。
- Pull 的变更成功持久化后才推进 `nextCursor`；在端侧存储支持范围内原子提交数据与游标，失败保留旧游标以便重放。
- `DEVICE_REVOKED` 停止同步并提示家长重新绑定；切换儿童或设备不得把原队列归到新身份。
- 资源包先下载到临时区域，校验清单、文件大小及 SHA-256，全部成功后原子切换；失败保留旧可用版本。
- 启动、返回前台、网络恢复和手动操作可触发同步，要防止并发重复启动同步任务；应用被终止或 H5 页面关闭后，不承诺即时后台同步。
- 离线星星是否预测、如何与服务端账本对账仍需统一设计；不得自行把本地预测数当成最终奖励，也不能静默丢弃离线完成记录。

## 儿童交互与媒体

- 一屏聚焦一个主要任务，主按钮至少 48dp，儿童端优先 56–64dp；复用品牌色、字号、间距与圆角 token。
- 答错用“再听一次”“再试试”等反馈；退出任务保留进度；页面进入时不突然大声播放。
- 录音由明确操作触发，展示录音状态、时长限制、停止和回放；离页释放录音与播放资源。
- H5 录音和 Service Worker 依赖安全上下文；NAS 普通 HTTP IP 地址不可作为真机验收环境。拒绝权限、不支持 API、存储不足都要有可恢复反馈。
- 儿童页面不暴露服务器 IP、调试日志和管理操作；长按可作为入口手势，不能替代家长验证。
- 未获得家长明确选择时不上传录音，更不接入第三方评分；示例数据不能包含真实儿童信息。

## 验证与交付

- 类型检查用 `npm run type-check`，H5 构建用 `npm run build:h5`，仓储失败行为用 `npm run check:repository`。没有 `dev:app` 脚本；Android 打包和真机不要写成已经通过。
- 同步改动覆盖重复 ACK、部分失败、Pull 中断、切换儿童、设备撤销、包校验失败以及旧包保留。
- 双端修改分别核对 Android 与 H5；有界面改动检查实际受影响尺寸和状态，必要时保留截图，不用模拟结果冒充真机。
- 离线场景验证：NAS 不可达时完成学习、应用重启后记录仍在、恢复网络后上传并回显正确且不重复发奖。
- 交付注明测试平台、权限/HTTPS 条件、实际通过项及待真机项；默认不提交 Git。
